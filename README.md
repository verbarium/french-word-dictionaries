# French Word Dictionaries And Word Lists

**Free, documented French dictionaries and word lists, ready to drop into a project.** A clean French dictionary with definitions, word frequency, Scrabble, Wordle and Sutom word lists, crossword clues, synonyms, antonyms and anagrams. Every dataset is CSV first, openly licensed and available on GitHub, Kaggle and Hugging Face.

They are built from the data behind four free word sites, [Mot Valide](https://www.motvalide.fr/), [La Petite Case](https://www.lapetitecase.fr/), [Synopedia](https://www.synopedia.com/) and [Anagrammio](https://www.anagrammio.com/).

## The Sites Behind The Data

- [Mot Valide](https://www.motvalide.fr/), French Scrabble word checker with definitions and anagrams
- [La Petite Case](https://www.lapetitecase.fr/), French crossword and arrow-word solver
- [Synopedia](https://www.synopedia.com/), synonyms and antonyms in six languages
- [Anagrammio](https://www.anagrammio.com/), anagram solver in five languages
